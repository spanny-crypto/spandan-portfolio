QUICK START (3 STEPS)
================================================================================

1. PUSH TO GITHUB
   - Create repo on github.com: spandan-portfolio
   - Run in project directory:

     git remote add origin https://github.com/YOUR_USERNAME/spandan-portfolio.git
     git branch -M main
     git push -u origin main

2. DEPLOY TO NETLIFY
   - Go to app.netlify.com
   - Click "New site from Git"
   - Select GitHub → spandan-portfolio
   - Netlify auto-detects build settings
   - Click "Deploy"

   Your site goes live in 2-3 minutes.

3. YOUR LIVE URL
   - https://spandan-portfolio.netlify.app
   - (or custom domain after connecting)

================================================================================
TO EDIT CONTENT
================================================================================

All portfolio content is in ONE file: data.ts

Examples:

• Add a new project → edit projects array in data.ts
• Update achievements → edit achievements array
• Modify timeline → edit timeline array
• Change colors → edit tailwind.config.js
• Update social links → edit social object in data.ts

Then:
  git add data.ts
  git commit -m "Update portfolio"
  git push origin main

Netlify auto-deploys. Your site updates in 2 minutes.
